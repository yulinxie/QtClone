# Visual Studio 2010 集成

QtClone 的主要目标编译器就是 **VS2010 / v100**：代码只使用 C++03 + VC10 已支持的
C++0x 子集（`nullptr`、`auto`、lambda 可用但框架本身没依赖），没有 moc、没有第三方库。

---

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| 编译器 | Visual Studio 2010（`cl 16.00`，PlatformToolset `v100`），x86 或 x64 |
| SDK | Windows SDK 7.0A（VS2010 自带）；`gdiplus.h` 在其中 |
| 运行时 | `/MD`（MultiThreaded DLL），Unicode（`/DUNICODE /D_UNICODE`） |
| 依赖库 | `user32 gdi32 gdiplus comctl32 comdlg32 shell32 ole32 oleaut32 shlwapi uxtheme imm32 advapi32` |
| 字符集 | Unicode；源文件含中文时**必须存成 UTF-8 with BOM**（VC10 不认 BOM-less UTF-8 字形面量） |

已验证：`MSBuild.exe QtClone.sln /p:Configuration=Release /p:Platform=Win32`（MSBuild 4.0）
与 `build.bat`（vcvarsall x86）都能完整构建并跑通自测。

---

## 2. 解决方案结构

`QtClone.sln`（VS2010 Format 11.00）包含 5 个项目：

| 项目 | 类型 | 依赖 | 说明 |
| --- | --- | --- | --- |
| `qtc` | 静态库 | — | 框架本体（core + gui + widgets） |
| `qtcuic` | 控制台程序 | qtc | `.ui` → `ui_*.h` |
| `wfdesigner` | Windows 程序 | qtc | 设计器（入口 `main` + `/ENTRY:mainCRTStartup`） |
| `gallery` | Windows 程序 | qtc | 控件画廊 |
| `wf_form` | Windows 程序 | qtc, qtcuic | 演示 `.ui` 的 CustomBuild + 生成代码 |

所有项目：

```xml
<PlatformToolset>v100</PlatformToolset>
<CharacterSet>Unicode</CharacterSet>
<AdditionalIncludeDirectories>$(SolutionDir)include;$(SolutionDir)src\gui;...</AdditionalIncludeDirectories>
<OutDir>$(SolutionDir)out\$(Configuration)\</OutDir>
```

GUI 程序使用 `main()` 但 `/SUBSYSTEM:WINDOWS` + `/ENTRY:mainCRTStartup`，
这样既能用控制台 `main` 写法，也不弹出控制台窗口。

---

## 3. 把 .ui 接进你的工程

1. 把 `Form1.ui` 加入工程（VS 会识别为 Custom Build Tool）。
2. 自定义生成步骤（见 `docs/designer.md` 第 5 节），命令调用 `qtcuic.exe`。
3. 项目 `AdditionalIncludeDirectories` 加入 `$(IntDir)`。
4. `#include "ui_form1.h"`，按示例写窗类。

> 不需要 moc：`QTC_OBJECT` 是普通宏，信号是模板成员，属性表是静态数组。
> 因此工程里没有"每个头文件一个自定义生成项"的负担。

---

## 4. 在自己的工程里使用（手动配置）

1. 编译 `qtc.vcxproj` 得到 `qtc.lib`（或直接用 `out\wf.lib`）。
2. 工程属性：
   * C/C++ → 常规 → 附加包含目录：`<QtClone>\include`
   * C/C++ → 预处理器：`UNICODE;_UNICODE`
   * 链接器 → 附加依赖项：上表 12 个 lib + `qtc.lib`
   * 清单：建议嵌入 `res/app.manifest`（comctl32 v6 视觉样式 + DPI 感知 + UTF-8），
     否则系统控件（滚动条等）外观会退回经典风格。
3. 代码里 `#include <qtc/QtWidgets.h>` 即可。

`res/app.manifest` 已提供，可作为你的工程模板。

---

## 5. 为什么不用 moc

* 少一个构建前置工具（VS2010 的 CustomBuild 配置对新手是门槛）。
* 头文件可以被任意工程直接包含，不需要"先生成再编译"。
* 代价：信号要写成 `Signal<void(int)>` 成员，属性要手写表 + switch；
  换来的是完全可读、可调试的普通 C++。

详见 `docs/reflection.md`。

## 6. 常见问题

**Q: 编译报 C2001「常量中有换行符」/ 中文乱码？**
源文件必须是 UTF-8 **带 BOM**。`tools` 里的脚本与 `uicgen` 生成的文件都带 BOM。

**Q: 链接报 `__imp__RegOpenKeyExW` 等未解析？**
把 `advapi32.lib` 加进附加依赖项（`build.bat` 与 sln 已含）。

**Q: 程序启动无窗口 / 立即退出？**
GUI 项目需要 `/SUBSYSTEM:WINDOWS` 与 `/ENTRY:mainCRTStartup`（或改用 `WinMain`）。

**Q: 字体发虚、字号偏小？**
框架在 `QApplication` 构造时调用 `SetProcessDPIAware()`，字体按 96 DPI 解释；
在高 DPI 屏上如需 150% 缩放，调用 `QApplication::setFont()` 调整字号即可。

**Q: 控件不显示？**
父控件要先 `show()`，并且加入布局或显式 `show()`；设计器里的控件由画布统一管理。
